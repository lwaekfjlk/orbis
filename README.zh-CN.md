# TELLURIC 13 — Continuous Atlas

## 这版解决什么

城市不是点进去的独立沙盘，而是原世界上的三维建筑层。世界、地区、城镇和建筑共用同一张可见地图、同一个渲染器、同一个坐标系和相机。滚轮接近城镇时加载其道路、城墙、城堡、圣殿与住宅。周围山坡、冰川、湖岸、河谷和海岸不会被城市模板替换。

## 传说地点

七处传说地点由已完成的物理模型推导，而不是凭空叠在地图上：巨龙之源（The Dragonwell）取全世界流量最大河流的真实源头，天池（The Skymirror）取全世界最高的静水水面，另有 The Nightspire（最高峰）、The Drowned Choir（最深海渊）、The Emberthroat（最强活火山）、The Weeping Stair（最大跌水）、The Hollow Crown（最大内流盆地）。每处都同时给出传说文本和它被选中的实测依据，并以金色标记、地图名称、搜索结果和详情卡片四种方式呈现。世界里若没有对应地貌，就没有这处传说。用 **Legends** 开关控制显示。

地形细分跟随相机：一个网格单元在屏幕上足够大时最多细分八份，画面同时以高于 CSS 分辨率渲染。细分顶点采样的仍是同一张母表面——增加的是三角形，不是地形。

## 运行

直接用现代桌面浏览器打开 `dist/telluric-onemap.html`。浏览器需要允许 JavaScript 和 Blob Worker；没有网络资源、账号、API 密钥或 CDN。Worker 不可用时有主线程回退，复杂建筑生成会暂时变慢。

开发运行使用 Node.js 20+，没有第三方 npm 包，不需要 `npm install`：

```bash
npm run dev
```

打开终端显示的本机地址。修改源码后执行 `npm run build`；这个命令会重新生成网格 Worker 的源码和离线 HTML。**添加、修改渲染模块后也需要重新 build，避免 Worker 与主线程使用不同版本。**

## 地图操作

- 滚轮 / 触控板：围绕指针连续缩放；覆盖世界到建筑的尺度。
- 拖动：移动地图。Shift + 拖动或右键拖动：改变方位和俯仰。
- 搜索城市，点击 **Zoom**：镜头平滑接近那个真实位置，不开城镇窗口。
- 双击地图上的城镇：同样只改变镜头；双击建筑继续接近该建筑。
- 点击建筑：出现小卡片。**Closer** 放大，**Details** 只开可关闭的信息抽屉。
- **Wider setting**：向后拉远，看到原有山脉、湖岸与城镇的相对关系。
- 左上角 TELLURIC 或 H：镜头拉回世界。
- 底部 Play / +1 / +10 / +50：继续原文明模拟。Regenerate：生成新世界及其文明。
- 更多菜单保留保存、读取、历史与导出。建筑详情可安排公共建设及导出所在城镇的 GLB。

默认种子 `Aereth-47` 的 `Stonefall 5` 是干燥湖盆旁的冰川山麓。不能因为旁边有雪山就把谷底全部刷成白色。`Silverford` 展示同一地图中的大型圣殿和水岸。更换种子后，地名和环境会变化，不强制每个种子包含它们。

## 道路、港口与小人

城镇之间的陆路由未修改的栅格一次多源搜索得出：只走陆地，遇到真实河道才架桥，绝不在开阔水面上画路。干线不是按城镇大小指定的，而是由整个路网上的模拟通行量自然浮现。真正有岸线的城镇会得到码头：世界尺度上是栈桥与仓库符号，走近后是码头平台、伸入水中的栈桥、系泊的船、货栈、吊杆和灯标——都建在既有岸线上，不会挖出新的水面。

街上和路上的小人取自该行省**已有的**人口构成（七个族群），每个小人是一次抽样，并不代表旁边那栋房子里住着谁，也不会给任何建筑、街道或街区标注族属。**族群之间只有外观不同**：身高、体型、颜色和一处剪影特征。速度、路线和能力完全一致，`Folk.speedOf` 根本不读取族群字段，并有测试锁定这一点。

这一层不参与模拟：道路不改变贸易成本，小人不运货、不传教、不接触。地图上新增 **Roads & ports** 与 **Townsfolk** 两个开关。WebGL2 下小人会走动；使用 Canvas 软件渲染或系统开启「减少动态效果」时，街上依然站满了人，只是不动。详见 [docs/ROADS_PORTS_FOLK.md](docs/ROADS_PORTS_FOLK.md)。

## 地理一致性

`src/continuous/atlas-space.js` 定义世界网格与城镇坐标间的映射。原世界的海拔、水面和储冰量决定显示表面。世界网格三角形被细分时沿用同一表面，不能增加新的山、湖或海岸。建筑群放在可建地块上，刚性结构采用取样后的台基；道路等贴地细节沿地面投影。没有独立的地形底座，也不把概念图贴在背景上。

地理和文明生成源文件保持上一版；城市布局及建筑套件继续使用已有程序化规则。视觉坐标采用原来的夸张比例，**不是实测米制模型**。细化三角形只改善显示，不增加新的真实地理信息。复杂坡地台基和城防仍是示意几何，不是工程结构校核。

## 性能与分级细节

重型建筑网格在 Web Worker 中生成；全世界地形保留在原画布。只保留最多两座已细化城镇的网格缓存。地区尺度先显示简化轮廓，继续接近才显示精细屋顶、圣殿和建筑部件。细节首次加载和分级切换仍可能出现等待或模型显现；**这不是承诺电影级无缝流式渲染或 60 FPS**。软件渲染的大型圣殿依然会较慢。

默认探索不使用旧的 city / landmark 弹窗。旧模块还保留在源码中，作为布局、模型及兼容接口，不是应用的浏览入口。

## 开发入口

```text
src/world/roads.js       城镇间陆路、桥位与码头选址（只读派生，带 WeakMap 缓存）
src/civilization/folk.js 族群抽样与小人运动（位置是时间的纯函数）
src/render/road-renderer.js  道路、桥、码头与航线几何（扩展已锁定的 world-renderer）
src/render/folk-renderer.js  小人网格，每帧重建，不触发阴影重算
src/continuous/
  atlas-space.js       唯一地理映射、地面取样、射线
  city-layer.js        原地图内的城市网格、缓存与分级显示
  worker-body.js       后台网格生成协议
  generated-worker.js  build 生成，不手工编辑
src/ui/continuous-map.js 镜头、鼠标、触屏、点选、详情、小人动画节拍
styles/continuous.css  单地图增量界面
```

原 `src/world`、`src/civilization`、`src/towns`、`src/city`、`src/landmarks` 与资源仍包含在完整项目中。

```bash
npm test

npm run test:folk

```
